Gallery 是 Canvas、3D 片场与 Video Editor 共享的项目级媒体工作台。切换工作区不会复制资产。
评分、标签、颜色、显示名称、备注、文件夹、回收站状态和视图偏好都保存在同一份带版本的 Creative
工作区中，并参与撤销/重做。

## 浏览与整理

Gallery 汇总分镜镜头、片场截图、录制、参考图，以及导入的图片、视频和音频。它支持：

- 网格、瀑布流、列表和按日期分组的时间线视图；
- 按集合、媒体类型、最低评分、标签、颜色和重复项筛选；
- 搜索名称、备注、标签、ID、MIME/来源字段及嵌入式提示词元数据；
- 嵌套文件夹和拖放移动素材；
- 按项目持久化排序、缩略图大小、当前文件夹、子文件夹包含规则和回收站视图；
- 面向大型目录的有界原生离屏渲染。

评价、命名、归档或移入回收站会把素材登记为项目资产；导入素材在导入时登记。因此，即使 Gallery
素材还没有被 Canvas 节点或 Video 片段引用，工程包也会保留它。

## 评价与批量操作

选择单项后可以编辑显示名称、文件夹、颜色、0–5 星评分、标签和备注。多选后可以批量修改评分、
颜色和标签，移动文件夹，发送到 Canvas，并通过模板或正则表达式预览后重命名。

模板支持 `{name}`、`{index}`、`{type}`、`{date}` 和 `{ext}`。Director 会在应用前展示完整预览，
并把整个批次记录为一个历史单元。

移入回收站可以恢复。永久删除必须明确确认，只允许删除导入媒体；Canvas 或 Video 仍有引用时会拒绝。
片场拥有的镜头、截图和录制仍由来源工作区管理。

## 查看与对比

双击卡片或点击**打开查看器**进入完整媒体界面。图片/镜头支持缩放，视频与音频使用原生播放控件。
查看器会显示尺寸、时长、MIME 类型、字节大小、创建时间和稳定媒体 ID。

可以选择另一条结果进行 A/B 并排对比；两张图片还支持可拖动的擦除对比。上一项/下一项均有可见控件，
流程不依赖快捷键。

## ComfyUI 元数据

PNG 导入会在大小限制内读取 `tEXt`、`zTXt` 和 `iTXt` 块，包括常见的 ComfyUI `prompt` 与
`workflow` 载荷。Gallery 会提取可搜索的正向/负向提示词和 seed，并保留原始有界元数据。
**发送工作流参数到画布**会创建带稳定媒体引用的节点，写入提示词摘要和 prompt graph；工程导出/导入后
仍能保留来源 ID 与生成上下文。

## 图片与视频生成

点击 Gallery 工具栏中的**生成**会打开 ComfyUI 制作抽屉。这里连接真实 provider，不使用占位渲染器：

- 导入任意 ComfyUI **API 格式**工作流 JSON，并检查节点类型；
- 自动暴露提示词、负面提示词、尺寸、seed、sampler、scheduler、模型、LoRA 和其他类型化标量输入；
- 选择一个或多个节点，以固定、递增或随机 seed 提交 1–32 份任务，并遵守各节点并发上限；
- 显示在线/忙碌/离线状态、远端队列、RAM/VRAM、当前工作流阶段、多 sampler phase 与采样步数；
- 取消队列/运行任务、重试失败任务、中止节点并释放模型/显存；
- Gateway 中断后依据 ComfyUI history 核对结果，不伪造成功状态。

生成任务使用共享的 append-only production-job attempt 契约。完成文件会下载到
`data/production-jobs/<job>/attempts/<attempt>/`，记录哈希，并只通过鉴权 artifact 接口读取。
**加入 Gallery**再把受保护字节导入浏览器媒体库，保留提示词、seed、工作流、节点、参数和原始 PNG 元数据。

模拟 ComfyUI 集成测试已覆盖 HTTP、工作流与 artifact 流程；节点配置成功并不等于真实硬件成片，部署验收
仍必须保存一次真实 GPU 输出回执。

## 工程包与 Agent 控制

**导出工程**会包含仅存在于 Gallery 的已登记媒体字节、文件夹、评价、偏好和嵌入式生成元数据。
导入会先验证归档路径、声明大小、CRC 与媒体上限，再修改持久媒体库，并把 Gallery、Canvas、Video
中的引用一起映射到新 ID。

`director_creative observe` 会返回 `gallery` 投影。Agent 可执行可逆的元数据修改、移动、批量改名、
回收站/恢复、文件夹和偏好操作，并与 Canvas/Video 共用快照指纹、幂等、原子批次和撤销规则。
永久删除会移除浏览器持有的持久字节，因此继续只允许人类确认流程执行。

操作名与保护规则参见 [Canvas、Video 与 Gallery Agent](/zh/agents/creative-workspaces/)。
