本矩阵是参考 Director's Console 与 Trigen 后形成的实现清单。只有当功能在产品中可达、
具有持久化数据或产物协议、人与 Agent 的控制面一致，并且有针对性测试证明边界时，
才可以标记为完成。参考仓库中存在一个文件或类，不代表该功能已经可用于生产。

最后审计：**2026-08-07**。

## 明确排除

根据产品要求，快捷键说明浮层与新手引导不在本次范围。纯营销声明、死代码、仅 mock 的提供者，
以及没有来源却声称“历史准确”的预设数据，都不会在未达到 Director 同等证据门槛前被计为集成目标。
