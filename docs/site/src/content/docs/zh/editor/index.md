应用提供四个顶层工作区：**画布**、**3D 片场**、**视频编辑器**和 **Agent**。画布负责组织镜头意图与媒体溯源，3D 片场负责 blocking、相机和动画，视频编辑器负责在画面与音频轨道上编排持久化媒体，Agent 运行持久的 coding-agent 会话。项目媒体仍在这些制片工作区里的 Gallery 中。3D 片场由三个持久区域组成：

- **场景树**：制片对象、组、角色、相机和层级控制；
- **3D 视口**：布景、选择、变换工具、相机预览和视觉反馈；
- **检查器与工具**：场景属性、建模和资产。

视口下方始终可以使用帧时间线，用于动画、相机动作、镜头范围、录制和分镜工作。

通过 `npm run blender` 启动后，同样的三个区域会直接操作绑定的原生场景。原生根对象进入
现有场景树，Stage 负责选择和根变换，右侧检查器把 Director 属性与按对象限定的 Mesh/Rig 工具
连续组合起来；它仍是一条 Director 工作流，而不是第二个建模工作区。详见
[场景与资产](/zh/editor/scenes-and-assets/)。

## 核心交互模型

### 选择

在视口或场景树中点击对象。当场景包含大量对象时，可以使用套索选择。选择属于 UI 状态，只有应用编辑操作后才会改变项目。

### 变换

通过视口 gizmo 和检查器移动、旋转或缩放对象。Director 保存有度量单位的变换。基本体的
`position` 是**地面枢轴（底部中心）**，不是几何中心：3 米高的墙立在地面上应写
`position.y = 0` 且 `scale.y = 3`；写成 `y = 1.5` 会把墙抬离地面。天花板底面要贴在 3 米处
时应写 `position.y = 3`，而不是 `3 + 厚度/2`。导入资产则使用可视边界元数据计算落地位置和
变换原点。

### 分组

当多个对象需要作为整体移动时，可以从当前选择创建组。父对象的运动会影响子对象；除非用户明确授权覆盖，否则锁定对象不会被 Agent 修改。

### 导航

在 Director 视图中进行环绕、平移和缩放。相机预览和活动相机捕获与编辑器导航相机分离，因此检查场景不会悄悄改变镜头。

## 仅供编辑器使用的辅助元素

视口可能显示网格、标签、相机视锥、变换 gizmo、轨迹辅助线、选择边界和导航控件。相机捕获与录制的干净输出会排除这些辅助元素，因此白模画面可以直接作为后续视频生成的证据。

## 项目级操作

Director 支持项目导入/导出、场景复制、制片引用、相机缩略图、分镜镜头，以及与本地网关进行版本感知同步。

若要逐项核对每个图标按钮的含义与状态，请参阅[界面图标对照表](/zh/editor/ui-icons/)。
