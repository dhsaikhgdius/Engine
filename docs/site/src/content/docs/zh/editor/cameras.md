Director 将相机视为带有镜头、宽高比、目标和可选镜头行为的制片对象。编辑器导航视图与活动镜头相互独立。

## 相机属性

| 属性              | 含义                                                    |
| ----------------- | ------------------------------------------------------- |
| 名称              | 易读的镜头或 rig 名称                                   |
| 位置              | 场景坐标中的相机位置                                    |
| 旋转 / 目标       | 相机朝向或观察目标                                      |
| 焦距              | 以毫米为单位的镜头焦距                                  |
| 传感器 / filmback | Super 16、Super 35、Full Frame/VistaVision 或 65mm/IMAX |
| 光圈              | 驱动曝光和色彩捕获景深的物理 f 值                       |
| 对焦距离          | 以米为单位的薄透镜对焦平面距离                          |
| 快门 / ISO        | 真实渲染曝光控制；快门也携带运动模糊意图                |
| 近 / 远裁剪       | 真实视口、PIP、截图和视频帧的裁剪平面                   |
| 变形压缩          | 水平投影去压缩与椭圆散景控制                            |
| 宽高比            | `16:9`、`9:16`、`1:1`、`4:3`、`1.85:1` 或 `2.39:1`      |
| 手持晃动          | 关闭、轻微、中等或强烈                                  |
| 动作模式          | 静止、摇摄、俯仰、推进、拉远、跟随/推轨或弧线           |
| 目标对象          | 可选的语义主体绑定                                      |

焦距和传感器门共同决定视场角，两者都不是装饰性标签。Director 会将选定输出宽高比适配到物理画幅中：宽画幅会裁掉上下，竖幅或更窄的画幅会裁掉左右。应有意识地选择相机与主体距离、传感器和镜头，不要用对象缩放去补偿所有构图问题。

旧项目会迁移到 Full Frame/VistaVision，并保留原有视图。Stage v5 仍携带等效的全画幅焦距，因此与旧协议交换数据时可以保持构图，即使旧协议无法保留传感器名称。

近裁剪和远裁剪会应用到实际的 Three.js 相机。光圈、快门角度、ISO 和时间线 FPS 会转换为快门秒数、EV100 和校准后的渲染曝光倍率。filmback、裁切、焦距和变形压缩也会改变实际投影：压缩会改变水平投影比例，同时保持选定的垂直构图。

对于不含辅助元素的**干净彩色**输出，Director 会渲染色彩目标和硬件深度，并应用薄透镜景深。弥散圈根据焦距、光圈、对焦距离和实际使用的传感器高度计算；变形压缩会产生椭圆而不是圆形的模糊。PIP 使用持久化的低质量通道（半分辨率、较低采样数）保持响应，离线干净捕获则使用高质量通道。`depth`、`normal` 和 `object-id` 是技术数据通道，因此会刻意绕过景深。运动模糊仍记录为快门意图/元数据，而不是由此渲染器模拟。

## 相机视口属性

浮动相机属性面板可以快速访问名称、位置、旋转、焦距、宽高比和手持设置。面板可拖动，其会话位置与项目内容分开保存。

## 掌镜模式

选择 **开始掌镜**，点击视口激活控制，然后按住鼠标左键拖拽转向。松开左键会结束拖拽，但不会停用键盘移动；Director 不会启用 Pointer Lock。使用 `W` `A` `S` `D` 移动，`E` / `Q` 升降，`Shift` / `Alt` 加速或精细移动，滚轮调整 FOV，`Enter` 记录轨迹点。`F` 会锁定当前目标（没有目标时锁定当前视点）；锁定后，移动会围绕目标环绕或推拉。再次按 `F` 即可回到自由移动。点击视口外会释放控制，按 `Esc` 退出掌镜模式。

## 画中画

相机预览会渲染选定或活动相机，同时主视口保持 Director 视图。它使用与镜头相同的物理投影和低质量电影干净通道，但不会读取像素，也不会为每一帧分配新的渲染目标。使用锁定控件，在检查其他对象或相机时保持特定的相机预览。预览面板也可以重新定位，不会改变镜头。

## 构图与目标

目标可以是：

- 明确的世界空间点；
- 对象绑定；
- 由时间线求值的目标；
- Agent 选定、供取景和审计使用的主体。

执行 Agent 工作时，将 `camera_id` 与 `subject_id` 一起传给 `audit`，即可进行相机空间归一化检查，包括裁剪、主体出框、比例和构图。构图评估同时报告每个主体的 `visible_fraction`（投影包围范围落在画面内的比例）与 `occluded_by`（挡在镜头前方的物体），Agent 循环无需读取像素即可确认主体真的在画面里。

## 镜头语言

一个共享的镜头语言模块会把每一对相机/主体读成剧组词汇——景别（大远景到大特写）、方位（正面、前四分之三、侧面、后四分之三、背面）、机位侧、高度（贴地到俯瞰）、最接近的定焦镜头，以及实测主体距离——并用同一组分档反向求解，因此按意图求解出的取景永远能读回同样的意图。相机画中画会实时显示这一读数（如 `CLOSE-UP · PROFILE L · EYE · 50MM`），`observe` 为每台相机发布完全一致的报告，视频提示词扩展也携带同样的实测取景。UI 与 Agent 对“35mm 中景侧面”不可能产生分歧。

Agent 按意图而非原始变换来编排取景：

- `frame_shot` 依据词汇（`size`、`view`、`side`、`level`、可选 `focal_length_mm`）相对主体对象摆放并对准既有相机。当请求在物理上不可能——例如广角镜头拍大特写会把相机放进主体身体里——求解器会沿定焦阶梯加长镜头或压平高度，并在结果里说明调整，而不是静默失败。
- `mark_camera_move` 把相机当前取景（rig 变换、对准点、视场角）钉为相机自身动画轨道上的一个关键帧。取景两次、各钉一次，就编排出一段运镜。
- `describe_camera_move` 为已钉轨道在两帧之间几何证明的运镜命名——推轨、推近/拉远、摇摄、俯仰、环绕、升降、变焦、滑动变焦——并返回可直接用于提示词的短语和逐段景别标牌。Stage 页签断开时也能从持久化项目求值。

## 相机动作

相机动作可以作为镜头意图保存，并在时间线上求值。需要精确运动时使用逐帧关键帧；需要让 Agent 仍能理解运动时，使用弧线等语义动作。

## 干净相机捕获

相机捕获会临时排除以下编辑器辅助元素：

- 网格和坐标轴；
- 相机视锥和 rig 图标；
- 变换控件和选择边界；
- 标签、轨迹辅助线和套索覆盖层。

输出帧代表用于审查或视频生成的白模镜头，而不是编辑器外壳。

为了后续合成和模型训练，Director 可以输出精确尺寸的 `clean`、PBR `albedo`/`roughness`/`metalness`/`emissive`/`ao`/`shadow`、打包 `depth`、视空间 `normal` 和确定性的 `object-id` PNG 通道。米制浮点深度 EXR 与逐帧实例 JSON 均为可选；object-ID 结果包含该帧使用的稳定对象到 RGB 对照表。

## 持久化四视图

**四视图**工具会切换到持久化的裁剪布局，包含一个透视窗格和正交的顶视、前视、右视窗格。四个窗格都从同一场景和当前求值帧渲染；布局不会创建四个画布或四个场景根。四视图当前是检查模式：返回单一 Director 视图前，窗格导航和场景编辑交互都会禁用，避免将一个窗格的指针变换误应用到另一台相机。

## 常用焦距参考

| 焦距      | 典型用途                     |
| --------- | ---------------------------- |
| 18–28 mm  | 建立镜头或有意强调的广角透视 |
| 35 mm     | 自然广角和环境 blocking      |
| 50 mm     | 中性中景                     |
| 70–100 mm | 人像、细节或压缩式布景       |

这些是创作参考，不是校验规则。
