---
title: 参考图重建
description: 把照片或草图转换成有边界、可编辑且可溯源的 3D 片场计划。
---

入口位于 **3D 片场 → 模型库 → 参考图重建**。分析过程不会直接修改片场；Director 会先生成
可检查计划，只有用户保留的物体和灯光才会在应用时写入。

## 操作流程

1. 选择 PNG、JPEG 或 WebP。Director 会把最长边规范化到不超过 1280 像素，并拒绝编码后超过
   5 MiB 的输入。
2. 可填写“只重建建筑体块”等意图，并选择追加或替换模式。
3. 选择分析模式：
   - **自动**：使用可用的托管视觉 Profile；失败时明确显示降级；
   - **强制视觉模型**：必须存在已配置的托管视觉 Profile，失败时不会悄悄伪装成本地结果；
   - **仅本地脚手架**：只使用色板、亮度、边缘密度、前景覆盖率和宽高比，不属于语义看图。
4. 审阅摘要、置信度、警告、物体名称、基本体、颜色、放置意图、位置、缩放和建议灯光。
5. 应用计划。全部变化作为一笔可撤销的片场操作提交。

关闭或取消会中止正在进行的请求。如果分析后工程 revision 已变化，应用会被阻止，必须重新分析；
过期计划不会覆盖较新的片场编辑。

## 信任与来源

浏览器会对规范化图片计算 SHA-256。服务端会在调用 provider 前校验哈希、字节上限以及
PNG/JPEG/WebP 文件头。视觉模型只能提交严格 schema，且基本体和灯光词汇有界。ID、目标
revision、来源哈希、Profile、模型、token 使用、警告和输出 ID 均由 Director 控制。

应用后，工程会保存来源图片资产、一条 `referenceReconstructions` 计划记录，并在每个输出物体上
保存图片 reference binding。计划不保存来源 base64。Agent 创建物体时使用相同的
`reference_bindings` schema，因此人与 Workbench 创作的 provenance 含义一致。

## 支持边界

本功能生成的是可编辑 blocking 基本体。已配置的视觉 Profile 可以推断可见构图和近似物体类别，
但单张图片中的深度、尺度、遮挡和不可见表面仍是推断值。本地路径会明确标记为低置信度，也不会声称
识别了图片语义。它不是摄影测量、网格恢复，也不保证任何模型 provider 一定可用。
