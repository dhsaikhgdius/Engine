# End-to-End Tests

> Languages: **English** · [中文](README.zh-CN.md)

Playwright-based end-to-end test suite covering critical user flows in Director's video editor
and 3D stage. Tests run in headless Chromium against a pure-frontend Vite dev server (no
gateway/backend required). Uses `prefers-reduced-motion: reduce` to cut animation flake.

## Run

```sh
npm run test:e2e
```

This runs `playwright test --config tools/e2e/playwright.config.ts`. Playwright does not
auto-discover that file from the repository root.

Requirements: repository dependencies installed and a Playwright Chromium download
(`npx playwright install chromium`).

## Test specs

| File | English purpose |
|------|-----------------|
| `enter-video-editor.spec.ts` | Enter the video editor from the home page via workspace tab, verify empty timeline appears |
| `media-import.spec.ts` | Import a PNG asset, add to timeline via the "+" button, verify preview renders the image |
| `clip-context-menu.spec.ts` | Right-click a timeline clip, open context menu, and delete the clip |
| `timeline-editing.spec.ts` | Drag clips, scrub playhead, split with S key, undo |
| `media-drag-drop.spec.ts` | Real browser drag-and-drop: drag a media card onto a timeline track so it lands |
| `export-dialog.spec.ts` | Open the export dialog, inspect output summary, close with Escape |
| `stage-authoring.spec.ts` | 3D stage authoring: rename an object via the object tree, duplicate via clipboard shortcuts, undo both |
| `canvas-dag.spec.ts` | Canvas production DAG: add note nodes, auto-layout, connect an edge, reject cycles, delete the edge, undo |
| `gallery-media.spec.ts` | Gallery/media library: import a PNG in the Canvas workspace, verify the board node, search and collection filters |
| `render-golden.spec.ts` | 3D stage pixel-level regression snapshots: import a pinned project, sample multiple monitor modes and viewport pixels |

## Helpers

`helpers.ts` provides shared Playwright utilities:

- `FIXTURE_PNG_PATH` / `FIXTURE_PNG_NAME` — A solid-red 48×27 PNG generated by `fixtures/generate-fixtures.mjs`.
- `prepareCleanStorage(page)` — Clears localStorage, marks welcome guide as seen so tests start from a clean slate.
- `openVideoEditor(page)` — Navigates to `/`, switches to the video editor tab, waits for the timeline region.
- `importFixtureImage(page)` — Imports the test PNG through the hidden file input, waits for the media card.
- `addCardToTimeline(page, card)` — Hovers a media card, clicks the "+ 添加" button.
- `scrubRulerAt(page, offsetX)` — Simulates pointer scrubbing on the timeline ruler.
- `playhead` / `timelineClips` / `timelineRegion` / `videoTrackRow` / `timelineRuler` — Pre-built locators.

## Fixtures

The `fixtures/` directory contains binary and data fixtures for tests:

| File | English purpose |
|------|-----------------|
| `generate-fixtures.mjs` | Pure Node.js generator for the clean red PNG used in import tests (no external image tooling) |
| `director-e2e-red.png` | 48×27 solid-red PNG test asset, generated by `generate-fixtures.mjs` |
| `render-golden-project.json` | Pinned project file for 3D stage pixel snapshots (exported via the interchange menu) |

## Vite configs

| File | English purpose |
|------|-----------------|
| `vite.config.e2e.ts` | Merges `tools/vite.config.ts`, uses a dedicated `node_modules/.vite/director-e2e` cache to avoid cross-instance re-optimization races with a developer's `npm run dev` |
| `vite.config.golden.ts` | Frozen server: file watching and HMR disabled, separate cache dir, so repository edits during a run never trigger a mid-comparison page reload |

## Snapshot directory

`render-golden.spec.ts-snapshots/` holds pixel-level regression baseline snapshots for the
3D stage:

- `monitor-*-chromium-golden-darwin.png` — Fixed frames for 7 monitor modes (depth, mask, normal, objectid, previz, rgb, wireframe).
- `stage-viewport-chromium-golden-darwin.png` — Full-viewport snapshot, threshold `maxDiffPixelRatio: 0.01`.

Snapshots are rendered under headless Chromium via SwiftShader, and pixels are deterministic
with a pinned Playwright version on the same machine class.

When a render change is intentional, refresh the goldens with:

```sh
npx playwright test --config tools/e2e/playwright.config.ts tools/e2e/render-golden.spec.ts --update-snapshots
```

## Playwright config

`tools/e2e/playwright.config.ts` configures:

- Test directory: `tools/e2e/`
- Two projects: `chromium` (video-editor tests, port 5178) and `chromium-golden` (pixel snapshots, port 5179, frozen server).
- Two webServers: one live-reload server with `vite.config.e2e.ts`, one frozen server with `vite.config.golden.ts`.
- `fullyParallel: true`, `retries: 2` in CI, `workers: 1` in CI.
- Viewport 1440×900, timeout 90s, `reducedMotion: "reduce"`.
