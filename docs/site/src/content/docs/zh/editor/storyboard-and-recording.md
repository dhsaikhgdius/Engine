## 分镜模型

分镜包含标题、梗概和有序镜头。每个镜头记录：

- 稳定的镜头 ID 与标题；
- 相机绑定；
- 起始和结束帧；
- 景别；
- 相机运动；
- 动作描述；
- 可选的精确帧缩略图证据：持久媒体 ID、SHA-256、机位/帧、画面尺寸、捕获时间和源项目版本。

分镜镜头引用项目相机和帧范围，而不是复制相机状态。这样变更可检查，编辑器也能识别失效引用。

卡片可以复制或前后移动。重排会保留每镜包含端点的时长，并从时间线起点重新生成连续区间。复制卡片会获得新 ID，并有意清除旧的帧绑定缩略图。

## 相机缩略图

场景和相机缩略图用于快速定位，它们的缓存属于会话数据，不会成为权威项目内容。分镜缩略图采用更强的契约：**捕获**会用该镜的精确机位在 `frameStart` 渲染无辅助干净 PNG，把字节存入 IndexedDB，只在 `DirectorProject` 中写入有界、带哈希的引用。

修改卡片机位或入点帧后，旧画面会标记为**待重拍**，不会被静默改名成新证据。**补齐画面**会依次捕获所有缺失/失效卡片；每张被接受的画面都受源项目版本保护。

## 打印与可验证 PDF

分镜导出对话框支持：

- A4 或 Letter，纵向或横向；
- 每行一至四列；
- 全部分镜或明确选中的子集；
- 可选的机位/帧/景别元数据和调度备注；
- 实时页面排版预览。

**下载 PDF**会先按 144 DPI 栅格化排版，再把 JPEG 页面嵌入标准 PDF，因此中文使用浏览器真实字体渲染。**下载可验证包**还会加入独立页面 JPEG 与 `manifest.json`。清单绑定项目版本、导出设置、有序镜头元数据、源缩略图来源、逐页 SHA-256 和最终 PDF SHA-256。

缺失、失效、旧相机后备或哈希不匹配的画面都会形成警告；哈希不匹配的字节绝不会被当作已验证证据。

Agent 使用 `storyboard_artifact` 的 `capture_thumbnail`、`capture_missing` 或 `export_pdf`。公开边界会注入缺失的项目 revision 与 retry key，浏览器执行边界要求两者都存在。精确重试会返回原结果，不会再次捕获、提交或下载。PDF 与图片字节留在浏览器中，工具链只传递有界清单。

## 制片与剪辑引用

网关制片清单保存带版本元数据的命名场景引用和剪辑镜头。关联镜头可以跟随源场景版本，固定镜头则保留审查时指定的源版本。

## 录制干净镜头

1. 选择活动相机，确认画中画输出。
2. 设置时间线 FPS。
3. 放置 IN 和 OUT 标记。
4. 排练该范围。
5. 选择实时录制，或选择确定性 IN/OUT 帧导出。
6. 在编辑器视口之外单独检查输出。

相机输出不包含编辑器辅助线。项目、活动相机、帧范围、宽高比和 FPS 共同构成输出如何生成的可复现记录。

## 导出模式：有意识地选择契约

| 控件                           | 输出                        | 时间契约                                                           | 适用场景                         |
| ------------------------------ | --------------------------- | ------------------------------------------------------------------ | -------------------------------- |
| 手动录制 / **自动导出 IN/OUT** | 支持时生成浏览器 WebM/MP4   | 实时浏览器 `MediaRecorder`；帧交付和最终编码取决于浏览器           | 快速审查视频                     |
| **确定性帧包**                 | 包含真实 PNG 帧和清单的 ZIP | 每个包含端点的 IN/OUT 采样会依次捕获，并带有明确的微秒时间戳和时长 | 可复现白模帧、视频生成输入、验证 |

确定性 ZIP 清单包含源/输出 FPS、帧范围、尺寸、逐帧 SHA-256 哈希和整包 fingerprint。导出会报告进度并支持取消。只有在提供真实的 WebCodecs 编码器和容器复用器时，Director 才会通过该路径输出可播放 MP4/WebM；否则真实结果是 PNG ZIP，而不是把文件重命名为 `.mp4`。

两条路径都会捕获活动相机的无辅助**干净**通道。因此物理 filmback、变形投影和干净通道景深会影响像素；网格、坐标轴、标签、相机辅助元素、选择控件、路径和套索 UI 不会进入输出。

## 导出项目证据

为了可复现交接，请保留：

- 导出的 `DirectorProject` JSON；
- 制片清单版本；
- 选定相机和帧范围；
- 审计结果和 trace；
- 相机捕获或录制；
- 依赖锁文件和运行时版本。
