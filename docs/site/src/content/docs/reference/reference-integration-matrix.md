title: Reference Integration Matrix
description: Audited integration scope for useful Director's Console and Trigen capabilities.
---

This matrix is the implementation checklist for the useful capabilities audited from
Director's Console and Trigen. A row is complete only when the workflow is reachable,
its durable data or artifact contract is defined, Agent and human control surfaces agree,
and focused tests prove the advertised boundary. A reference repository containing a file
or class is not evidence that its feature is production-ready.

Last audited: **2026-08-07**.

## Trigen

| ------------------------------------------------------------------ | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Conversational scene authoring                                     | **Implemented**                                   | Workbench schema, guarded authoring executor, HTTP/CLI/MCP/browser targets, undo receipts, and live Stage validation.                                                                                                                                                                                                                                                                                                                                                     | Every added Stage feature must remain observable, authorable, inspectable, lock-aware, revision-guarded, and idempotent.                                                                                                                             |
| PBR materials, texture maps, authored lights, environment, and fog | **Implemented**                                   | Director project schema/store, `DirectorPbrMaterial`, `DirectorSceneLighting`, Stage inspectors, Workbench actions, and focused tests.                                                                                                                                                                                                                                                                                                                                    | Future material fields must preserve imported-material safety and render/audit coverage.                                                                                                                                                             |

## Explicit exclusions

Shortcut reference overlays and first-run onboarding are excluded by product direction. Reference-only
marketing claims, dead code, mock-only providers, and unsourced “historically accurate” preset data are
not integration targets until they satisfy the same evidence gates as Director code.
