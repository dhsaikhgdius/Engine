画布、3D 片场、视频编辑器和 Gallery 是同一个场景范围制片项目的四个视图。切换工作区不会创建第二个项目，也不会复制媒体。画布、视频和 Gallery 状态按版本管理、支持撤销、按场景独立持久化，并可通过 `director_creative` 访问。

## 画布

画布是用于镜头意图和媒体溯源的空间制片图。它支持：

- `shot`、`image`、`video`、`audio`、`note` 和 `frame` 节点；
- 不同节点之间的有向边；
- 选择、平移、连接模式、节点移动、调整大小和删除；
- 使用持久媒体 ID 而不是临时对象 URL 的媒体卡片；
- 将 Stage 捕获和录制结果送回画布。

把支持的资产拖到画布上，会在放置位置创建节点。移动卡片不会改变媒体资产；删除卡片只会删除相连边，不会悄悄删除底层持久媒体。

画布有 240 个节点的安全上限。达到上限时不会通过删除最旧内容来腾出空间。请使用多个场景范围，或有意识地移除内容。

## 视频编辑器

视频编辑器使用有序的画面和音频轨道。当前片段控制包括：

- 起点、源 In、时长、切分和跨轨移动；
- 播放速率与源时长校验；
- 不透明度、音量、淡入和淡出；
- 缩放、位置、旋转以及 `contain` / `cover` 适配；
- 轨道可见性、静音、锁定、命名、添加和删除；
- 帧吸附、FPS、宽高比和导出质量设置。

预览与导出共享相同的时间映射和片段变换规则。片段不能使用超过源媒体末尾的范围，合并淡化不能超过片段时长。锁定轨道会拒绝 Agent 的片段编辑，而不是接受部分修改。

## 持久媒体

导入的图像、视频和音频字节存储在持久媒体库中。画布节点和视频片段保存媒体 ID 与元数据，不会把二进制嵌入项目 JSON。项目包只包含被引用的媒体，并在导入时校验大小、CRC 和路径。

如果预览丢失，不要猜测并替换 ID。请重新关联或重新导入源文件，并确认媒体类型与画布节点或时间线轨道匹配。

## 撤销与原子性

普通 UI 编辑参与工作区撤销/重做。Agent 的 `execute_batch` 会作为一个撤销单元记录。如果批次中的任一步失败，Director 会恢复节点、边、轨道、片段、设置和之前的选择，不会留下半应用的画布/视频意图。

## 制片验收

制片审计会检查图引用、缺失或不兼容媒体、未解析和断开的镜头、严重卡片重叠、无效源范围和淡化、重叠片段以及画面/音频覆盖。结构就绪不等于视觉证明：在宣布视觉任务完成前，请检查画布布局和视频预览中的代表性帧。

参见[Canvas、Video 与 Gallery Agent](/zh/agents/creative-workspaces/)，了解结构化控制契约。
项目级媒体评价、文件夹、对比、嵌入式生成元数据和回收站参见[项目 Gallery](/zh/editor/gallery/)。
